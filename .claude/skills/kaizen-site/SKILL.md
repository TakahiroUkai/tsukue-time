# 改善の1周(机タイム素材集だけの部分)

共通の手順(`TakahiroUkai/site-ops` の `.claude/skills/kaizen-loop/SKILL.md`)と一緒に使う。

## 基本

- 項目の接頭辞: `TT`(司令塔の `site` は `tsukue-time`)
- 既定ブランチ: `main`。公開URL: https://takahiroukai.github.io/tsukue-time/
- 改善の順番: 3番目(稼ぎのトリセツ → あんなことこんなことClaude → 机タイム素材集 → 注目銘柄メモの順に、実行のたびに次へ進む)
- 研究ノートの取得で分かったことは `LESSONS.md` に書く決まりがある。改善の回で研究ノートに触れたときも、それに従う。

## ユーザー役の読者像

`style.md` の「想定読者」の2つの場面を演じる。(1)スマホで、今すぐ印刷できるシートを数分で探す。(2)研究のページを、不安をあおられずに読みたい。トップページ → タブ → シートのページ → 印刷、研究の一覧 → 研究ノート、の順に使う。

## 事業推進役の観点(共通の観点に加えて)

目標への効き方を第一に見る(下の「目標の測り方」)。そのうえで:

- 欲しいシートに少ない操作でたどり着き、すぐ印刷できるか。
- 続けて来たくなるか(新しいシート、季節のテーマの見つけやすさ)。
- 集中タイマー(tsukue-timer)との行き来が自然か。

## 目標の測り方

- 目標の立て方・確かめ方は `TakahiroUkai/site-ops` の `docs/GOALS.md`、目標そのものは司令塔の `goals` にある。
- アクセス数: `TakahiroUkai/stock-memo2` の `data/analytics.json` の `key: "tsukue"`(path `/tsukue-time/`)。キーが `tsukue-time` ではないことに注意。
- 読み進めてもらう段では、`top_pages` のうち、タブ(`/tsukue-time/art/` など)、シートのページ、研究(`/tsukue-time/research/`)の閲覧を見る。トップ以外の閲覧数は `last30.views` からトップ(`/tsukue-time/`)の閲覧数を引いて求める。
- 印刷した回数は計測していない。
- 目標に効きやすい打ち手の例: シートの題名・説明文(検索結果に出る文)、サムネイルの見え方、季節のテーマへの導線、トップから読まれていないタブへの導線、研究ノートから関連シートへの導線、机タイマーへの導線。

## 机タイマーの項目の扱い

机タイマー(`tsukue-timer`)は机タイム素材集の1コンテンツで、単独の定期実行と目標を持たない(2026-11-07 に決定)。机タイマーの改善は、この机タイム素材集の回で行う。

- 司令塔の `items` から `site` が `timer`(接頭辞 `TM`)の項目も読み、状態が「実行して」「候補」のものを、机タイム素材集(`TT`)の項目と同じ並びで比べる。
- 効果は、机タイム素材集の目標(`TT-G01` など)にどう効くか(机タイマーへの導線、共有されたときの見え方など)で付ける。`goal` には、効く `TT-` の目標を入れる(関係がなければ空)。
- 優先度が、直そうとしている `TT-` の項目と同じか高いときは、その回で机タイマーの項目を直してよい(1回で直すのは全体で1〜2件)。直すときは `TakahiroUkai/tsukue-timer`(既定ブランチ `main`)(実行環境にあらかじめ clone されている。add_repo は使わない)を使い、そのリポジトリの `.claude/skills/kaizen-site/SKILL.md` の確かめ方に従う。
- ユーザー役・事業推進役の候補追加は、机タイム素材集を中心に行う。机タイマーで気づいたことは、`TM-` の項目として足してよい。
- 「要確認」の `TM-` 項目は直さない。

## 直してよい範囲

- `build.py` のページの組み立て、`static/` の CSS・JS、一覧の見せ方、既存のシートの題名・説明。
- 机タイマーを直す回だけ、`tsukue-timer` のリポジトリも変えてよい。それ以外では変えない。
- 直さない: `config/site.json` の affiliate・ads・ga4、`data/queue.json` の順番、`data/books.json`、`RULES.md` と `style.md`(変えたほうがよいときは「要確認」の項目にする)。公開ページに年齢の数字を書かない。

## 確かめ方

1. `python3 build.py`(シートの絵を変えたときは `python3 build.py --thumbs`)
2. `python3 check.py --visual` で ERROR が 0 件。A4 で1ページに収まり、印刷時に余計な要素が出ないこと。
3. 変えたページを、スマホ幅(iPhone 13 相当)のスクリーンショットで見て、崩れがないこと。
