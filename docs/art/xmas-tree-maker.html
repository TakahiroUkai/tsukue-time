クリスマスツリーメーカー(ぬりえ・シール台紙)

ツリーのかたちとかざりをえらんで、ぬりえやシール台紙を作れます。「もう1枚」を押すたびに、かざりの場所が変わります。

1. ツリーのかたち
2. かざりの数としゅるい(シール台紙は丸だけ)
3. 作るもの
線と かざりの大きさ
4. 名前(8文字まで・なくても大丈夫です)

入力した名前は、この端末のブラウザの中だけで使われ、サイトには送られません。

印刷画面で、倍率は100%にします。
このページを共有XLINEFacebook

JavaScriptをオンにすると、ここにツリーが表示されます。

使い方

  1. ツリーのかたちとかざりをえらびます。絵はすぐ下のプレビューに出ます。
  2. 「ぬりえ」はクレヨンで、「シール台紙」は点線の丸にシールを貼って使います。丸の中の色の名前は、貼るシールの目安です。
  3. 気に入らなければ「もう1枚」で、かざりの場所を変えます。
  4. A4で印刷します。印刷画面で、倍率は100%にします。
